# DnR Diffi｜离线文本对比与三栏编辑工具

**版本：v1.0.0** · **许可证：MIT**

DnR Diffi 是一款单文件、离线可用的三栏文本对比工具。左右两栏呈现原稿与修订稿的增删差异，第三栏供人工继续编辑，并标示内容与前两版的关系。适合核对 AI 重写、文案校订和日常纯文本审阅。下载 HTML 后在浏览器打开即可使用。

## 主要功能

- **三栏对照**：原始文本、对比文本和可编辑文本并排显示；高亮两版之间及编辑稿相对两版的差异。
- **可控比较规则**：按需要忽略换行、空格与制表符、大小写或常见中英文标点。忽略规则只影响比对，不删除原文字符。
- **本地版本历史**：自动记录编辑状态，最多保留 100 个版本，可从历史面板选择版本回退。
- **直接使用**：复制任一栏文本，切换深浅主题；应用本身无需账号或在线服务。

## 下载与使用

1. 下载本目录中的 `dnr-diffi-文本对比.html`。
2. 用现代浏览器打开，将原稿粘贴到“原始文本”，改稿粘贴到“对比文本”。
3. 查看增删高亮，在“编辑文本”栏继续修订；需要时调整顶部的忽略规则。
4. 点击右上角版本历史按钮查看或恢复本页保存的版本。

应用是一个不足 100 KB 的 HTML 文件。下载后直接打开即可离线使用；本目录的 README、LICENSE 和图标源文件 `Icon-Diffi.svg` 用于说明、授权与二次修改，运行网页不依赖它们。

## 数据保存与删除

DnR Diffi 的代码不会把输入文本发送到服务器。三栏文本和版本历史默认保存在当前浏览器的本地存储中。浏览器清除站点数据、使用隐私模式，或本地存储空间不足时，历史可能无法保留；页面会提示存储失败。重要内容请另行保存。

“清空全部”会记录为一个可恢复版本；若要删除本页的文本与历史，请在版本历史面板选择“彻底删除”。该操作不可通过版本历史恢复，主题设置会保留。

## 常见问题

### 能用它检查 AI 改写文案吗？

可以。把改写前后的文字放入左右两栏，增删内容会直接标出；第三栏用于人工继续修改。它展示文本差异，不评价文案质量。

### 忽略标点或换行会修改原文吗？

不会。这些选项只调整比对规则，文本框中的原文仍保留。

### 必须联网或安装软件吗？

不用。下载 HTML 文件后可在浏览器中离线打开。网页优先使用本机的 OPPOSans、PingFang SC；设备没有这些字体时会自动回退。发布包不包含字体文件。

### 版本历史会一直保留吗？

不保证。历史保存在浏览器本地，最多 100 个版本，并受浏览器存储空间与清理策略影响。存储不足时，页面可能只保存当前文本，并显示提示。
